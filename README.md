# Reverse: 1999 Gnomon

Fanmade information website for game Reverse: 1999

This website is not intended to replace wiki; instead, it will be more focused on gameplay information.

I made this website for faster search and view information since I couldn't find them anywhere else outside of the game.

Any suggestions or reported issues are appreciated.

## Sitemap

```
.
└── / (Home)
    ├── /characters (Character list)
    │   └── /:character-detail (Character detail)
    ├── /effects (Effect list)
    ├── /materials (Material list)
    └── /a-series-of-dusks (A Series of Dusks)
        └── /artefacts (Artefact list)
            └── /exchange (Artefact exchange)
        └── /mechanic (Mechanic)
```
