Acoustica artefact for **Argus**.

<br/> 

When Argus is a companion:

When entering a new area, randomly replaces 2 non-Impending Crisis, non-Treasure Hunt, and or non-Treasure Trove path nodes with Treasure Hunts and or Treasure Troves, and illuminates Treasure Hunts and Treasure Troves in the fog.

<br/> 

When Argus is deployed:

Whenever completing a Treasure Hunt/Treasure Trove, *[Miracle of a Hundred Eyes]*'s Insight III effect triggers an additional 1 time. 

:text[Enhance requirements: When Argus is a companion, complete a Treasure Hunt or Treasure Trove 0/1 time.]{className="text-enhance"}

<br/> 

When Argus is deployed:

At the end of the round, casts a *[No Mark Unstruck]* without consuming Moxie. For each Treasure Hunt/Treasure Trove completed, this *[No Mark Unstruck]* deals an additional (ATK x **500%**) Genesis DMG, capped at an additional (ATK x**2000%**) Genesis DMG. 

:text[Enhance requirements: When Argus is a companion, complete a Treasure Hunt or Treasure Trove 0/3 times.]{className="text-enhance"}
