Acoustica artefact for **Ezra**.

<br/> 

When Ezra is deployed:

At the start of the round, for each mushroom present, lose (own current HP x**10%**) HP and recover (Missing HP **15%**) HP for all allies, this effect can critically hit.

<br/> 

When Ezra is deployed:

Obtain 1 The Incinerator (triggers up to 1 time). Whenever completing an Impending Crisis, obtain an additional The Incinerator. For each The Incinerator in the layout, gain Max HP **+10%** for self. 

:text[Enhance requirements: When Ezra is a companion, complete 0/1 battle.]{className="text-enhance"}

<br/> 

When Ezra is deployed:

Upgrades all The Incinerators in the layout: Whenever casting an Aid incantation, the number of effects granted from :effect{code="COLLECTION_OF_PERMANENT_BUFFS"} is increased to 5 types. 

:text[Enhance requirements: When Ezra is a companion, complete 0/3 battles with The Incinerator in the layout.]{className="text-enhance"}
