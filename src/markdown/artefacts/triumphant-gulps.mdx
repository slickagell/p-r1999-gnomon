Acoustica artefact for **Lilya**.

When Lilya is a companion: For every 3 Present Dangers completed, gains 3 Flammenbrand.

When Lilya is deployed: After actively casting an incantation, casts an ultimate as a follow up attack (triggers up to 2 times per round).

<br />

When Lilya is deployed: When this unit performs an extra action, gain Moxie and an additional **100%** extra action damage.

:text[Enhance requirements: When Lilya is a companion, obtain 0/1 Flammenbrand.]{className="text-enhance"}

<br />

When Lilya is deployed: At the start of the round, generates a rank 3 *\[Crosswind Takeoff]*; for every 1 Flammenbrand in the layout, gains ATK **+15%** for self.

:text[Enhance requirements: When Lilya is a companion, complete 0/3 battles with Flammenbrand in the layout.]{className="text-enhance"}
