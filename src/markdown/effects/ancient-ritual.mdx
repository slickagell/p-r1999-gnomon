---
title: "Ancient Ritual"
code: "ANCIENT_RITUAL"
type: "CHANNEL"
isSpecific: "character"
---

While this channel status is active, enemies are treated as if :effect{param="hag-s-bane"}'s already triggered an extra (1 + the number of rounds elapsed in this channel status) times for the round.

At the end of the round, deduct (2 + the number of rounds elapsed in this channel status\*2) Moxie, and inflict (the number of Moxie deducted / 2) stacks of :effect{param="hag-s-bane"} on all enemies; if there isn't enough Moxie, then deduct all remaining Moxie, cast :effect{code="ENDING_POSE"}, and end this channel status; no Moxie is deducted on the first round of this channel status, and instead, 1 stack of :effect{param="hag-s-bane"} is inflicted.
