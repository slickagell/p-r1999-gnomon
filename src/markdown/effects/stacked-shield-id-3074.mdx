Additionally grants a Shield equal to a rank 2 *\[Stimulus to the Mind]* to all allies; and if a target is already holding a Shield, the value of this Shield is stacked on top of that target's existing Shield, up to a maximum Shield value of (own ATK x**60%**) HP.
