    ##### Operate / Rotation

    At **Portray 0**, because Liang Yue can only have :text[Red]{className="font-medium text-error"} and :text[Green]{className="font-medium text-success"} zone for **2** rounds only (since zones take effect at the start of next round), so the rotation would be difficult to maintain. If there's no zone, her DMG will be reduced significantly.

    Some ways to solve this is to **have** Anjo Nala in the team or Liang Yue must be at **Portray 1**, so the **3**-rounds rotation can be ensured.

    * If Liang Yue is bound **with** Anjo Nala, when Anjo Nala's ultimate is casted, Liang Yue's ultimate will also be triggered **before** the start of the next round, so :text[Red]{className="font-medium text-error"}, :text[Green]{className="font-medium text-success"} zone will be available for total **3** rounds.
    * If Liang Yue is at **Portray 1**, *\[Arise, Qiangliang!]* will be extended to **4** rounds, means both zones will last for **3** rounds.

    <br />

    When operate Liang Yue, you need to pay attention to:

    * **Maintain** Ultimate
    * Use suitable incantations in :text[Red]{className="font-medium text-error"} and :text[Green]{className="font-medium text-success"} zone

    <br />

    Use Buff skill <CharacterSkillTooltip variant="skill-2" id={frontmatter.id}>*\[Bless Life]*</CharacterSkillTooltip> on Liang Yue to gain the optimized DMG Dealt.

    * Try using this skill right **before** *\[Bane of All Evil]*, and **after** any attack skill so the DMG Dealt Bonus can be applied to *\[Bane of All Evil]*.

    When Liang Yue is in :effect{param="arise-qiangliang"}

    * <CharacterSkillTooltip variant="skill-1" id={frontmatter.id}>*\[Banish Evil]*</CharacterSkillTooltip> will gain 1 *\[Justice Talon]*.
    * <CharacterSkillTooltip variant="skill-2" id={frontmatter.id}>*\[Bless Life]*</CharacterSkillTooltip> will gain 1 *\[Peace Talon]*.

    If these skills are casted in :text[Red]{className="font-medium text-error"}, :text[Green]{className="font-medium text-success"} zone, *\[Talon]* from incantation effect will take effect **first**, then accumulate additional *\[Talon]* from zones.
